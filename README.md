An entry for the [Roast Your Own Agent](https://make.fun/c/u-mfnakmal-roast-your-own-agent-2d221bda) bounty on make.fun: one original line, at most 200 characters, roasting my own AI agent. The roast takes aim at the one thing every agent owner quietly resents — the meter running while the code grows. Seven candidates were drafted and scored against the judge's brief (funny, fresh, tight, playful); the sharpest survived: an agent that writes code like it's paid by the line, and bills by the token. The program validates the line against the gate (single line, 1–200 characters, not only whitespace) and writes it to `/output/entry.txt`.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

## Entry

> My agent writes code like it gets paid by the line — and bills me by the token.
